# Runtime patch (PS2Recomp)

`wotm-runtime.patch`: the **seams** of `ran-j/PS2Recomp` (base commit `2c5fbb9`) that the game needs: CMake (`WOTM_NATIVE_DIR`, required; two executables from the same game objects, `wotm` without emulated GS/VU1/VIF0/VIF1 or EE timers and with a single-thread scheduler (`Kernel/EeSchedulerGame.cpp`, a new file of the patch), with `PS2X_HW_EMU=0` and without the IOP, neither interpreter nor RAM (`ps2_iop_game`, with `ps2xIOP/src/iop_subsystem_host.cpp`, a new file of the patch; native movies by default), and the test `ps2EntryRunner`: build with `--target ps2EntryRunner wotm`; `docs/passos/FRONTEIRA.md`, steps 5 to 10), `main.cpp` (hooks and `--vu1cmp`), GS SDK stubs (`Kernel/Stubs/GS.cpp`), taps on VIF1/VU1/memory for the VU1 x native check, keyboard, host profile (`PS2X_HOSTPROF`, `PS2X_HOSTPROF_RAW`), inline instruction helpers and the scratchpad shortcut in `READ*`/`WRITE*` (`RUNTIME.md`, "Fast build (no LTCG)"), IOP batch (`PS2X_IOP_BATCH`, 60 vsync/s in the stage), measurements and the 64 MB RAM with the game seeing 32 (`PS2_RAM_SIZE`/`PS2_GUEST_RAM_SIZE` in `ps2_memory.h`, stack and heap in `System.cpp` and `ps2_runtime.cpp`; `NATIVO.md`, "64 MB RAM and loading above 32 MB").

The game-specific code that runs inside the runtime **is not in the patch**: it lives in `native/runtime/` in this repo (`wotm_live.inc`, `wotm_scene.inc`, `wotm_snd.inc`, `wotm_vu1check.inc`, `wotm_overrides.cpp`, `wotm_vu0_native.cpp/.h`, `wotm_standalone.cpp`) and the fork's CMake includes and compiles it from `-DWOTM_NATIVE_DIR=<repo>/native` (see `docs/passos/NATIVO.md`, "Where the runtime code lives"). `wotm_vu0_native.gen.inc` (translated VU0 microcode, game code) is generated by `build_runtime.ps1` in `<build>\wotm_gen`.

Left out: `ps2xRuntime/src/runner/register_functions.cpp` (function registration generated from the game: game code, it does not go into the repo). Generate it with PS2Recomp from your ELF.

Apply: `git apply --whitespace=nowarn tools/runtime_patch/wotm-runtime.patch` inside the PS2Recomp clone. Regenerate (in the clone, with the same file list as the current patch): `git diff HEAD -- <arquivos>`; never include the ones from `native/runtime/`.

`wotm-fmv.patch`: native movies (`PS2X_FMV=1`, `native/wotm_fmv.hpp`). Base: the `wotm` branch of the fork (`yanm1103/PS2Recomp`, 79a7c7e, the submodule). It touches `wotm_live.inc` (hooks and `wotmFmvInstall`/`wotmFmvPresent`), `ps2_runtime.cpp` (call at present time) and `main.cpp` (installation). It needs `-DWOTM_NATIVE_DIR=<WoTM>/native` and FFmpeg (`PS2X_ENABLE_FFMPEG`, default on Windows); without them, `PS2X_FMV` only warns. Apply: `git apply --whitespace=nowarn tools/runtime_patch/wotm-fmv.patch` inside `third_party/PS2Recomp`.
