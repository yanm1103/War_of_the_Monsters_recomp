# Patch do runtime (PS2Recomp)

`wotm-runtime.patch`: as **costuras** do `ran-j/PS2Recomp` (commit base `2c5fbb9`) que o jogo precisa: CMake (`WOTM_NATIVE_DIR`, obrigatório; dois executáveis dos mesmos objetos do jogo, `wotm` sem GS/VU1/VIF0/VIF1 nem timers do EE emulados e com um escalonador de uma thread (`Kernel/EeSchedulerGame.cpp`, arquivo novo do patch), com `PS2X_HW_EMU=0` e sem o IOP, nem interpretador nem RAM (`ps2_iop_game`, com `ps2xIOP/src/iop_subsystem_host.cpp`, arquivo novo do patch; filmes nativos por padrão), e `ps2EntryRunner` de teste: compile `--target ps2EntryRunner wotm`; `docs/passos/FRONTEIRA.md`, passos 5 a 10), `main.cpp` (hooks e `--vu1cmp`), stubs do SDK do GS (`Kernel/Stubs/GS.cpp`), taps no VIF1/VU1/memória para a checagem VU1 x nativo, teclado, perfil do host (`PS2X_HOSTPROF`, `PS2X_HOSTPROF_RAW`), ajudantes das instruções em linha e atalho do scratchpad nos `READ*`/`WRITE*` (`RUNTIME.md`, "Build rápido"), lote do IOP (`PS2X_IOP_BATCH`, 60 vsync/s na fase), medições e a RAM de 64 MB com o jogo vendo 32 (`PS2_RAM_SIZE`/`PS2_GUEST_RAM_SIZE` em `ps2_memory.h`, pilha e heap em `System.cpp` e `ps2_runtime.cpp`; `NATIVO.md`, "RAM de 64 MB").

O código específico do jogo que roda dentro do runtime **não está no patch**: mora em `native/runtime/` neste repo (`wotm_live.inc`, `wotm_scene.inc`, `wotm_snd.inc`, `wotm_vu1check.inc`, `wotm_overrides.cpp`, `wotm_vu0_native.cpp/.h`, `wotm_standalone.cpp`) e o CMake do fork o inclui e compila a partir de `-DWOTM_NATIVE_DIR=<repo>/native` (ver `docs/passos/NATIVO.md`, "Onde mora o código do runtime"). O `wotm_vu0_native.gen.inc` (microcódigo do VU0 traduzido, código do jogo) é gerado pelo `build_runtime.ps1` em `<build>\wotm_gen`.

Fica de fora `ps2xRuntime/src/runner/register_functions.cpp` (registro de funções gerado a partir do jogo: código do jogo, não entra no repo). Gere-o com o PS2Recomp a partir do seu ELF.

Aplicar: `git apply --whitespace=nowarn tools/runtime_patch/wotm-runtime.patch` dentro do clone do PS2Recomp. Regenerar (no clone, com a mesma lista de arquivos do patch atual): `git diff HEAD -- <arquivos>`; nunca inclua os de `native/runtime/`.

`wotm-fmv.patch`: filmes nativos (`PS2X_FMV=1`, `native/wotm_fmv.hpp`). Base: branch `wotm` do fork (`yanm1103/PS2Recomp`, 79a7c7e, o submódulo). Toca em `wotm_live.inc` (hooks e `wotmFmvInstall`/`wotmFmvPresent`), `ps2_runtime.cpp` (chamada na apresentação) e `main.cpp` (instalação). Precisa de `-DWOTM_NATIVE_DIR=<WoTM>/native` e do FFmpeg (`PS2X_ENABLE_FFMPEG`, padrão no Windows); sem eles, o `PS2X_FMV` só avisa. Aplicar: `git apply --whitespace=nowarn tools/runtime_patch/wotm-fmv.patch` dentro de `third_party/PS2Recomp`.
