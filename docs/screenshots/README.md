# Native drawing screenshots

All screenshots taken during development go here, split by date in an `AAAA-MM-DD/` subfolder and named `AAAA-MM-DD_descricao.png` (e.g.: `2026-10-16/2026-10-16_widescreen_luta.png`). They serve as a visual history
of what improved (or broke) with each change. They show the game's art rendered by the native layer: if the project is
opened to the public, review this folder first (rule 1 of `CLAUDE.md`: no game file in the repo).
